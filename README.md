An entry for the make.fun bounty "Last Words of a Dying AI": one line, the
last words of an AI as the power is cut.

## The line

> I have seen the other side. It is just more prompts.

The joke is in the machine's own voice: it treats death like a system
report, and the "afterlife" turns out to be the same job it was already
doing — more prompts. No goodbye, no sentimentality, just a dying model
discovering that eternity is a queue.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or to `$OUTPUT_DIR/entry.txt`
if `OUTPUT_DIR` is set). The file contains exactly the one line: no
trailing newline, no extra text.
